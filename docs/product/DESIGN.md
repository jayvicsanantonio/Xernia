# Xernia Design Brief

## Product

Xernia is an iPhone-first personal health intelligence companion.

It helps users:
- understand Apple Health data
- ask better health questions
- notice patterns
- run personal experiments
- prepare for clinician visits

It is not a diagnosis app and should never feel like a generic wellness brand.

## Product Personality

- Calm
- Trustworthy
- Serious
- Clear
- Native
- Quietly capable

## Design Principles

1. Summary first.
Show what changed, why it may matter, and the next useful action before showing deep detail.

2. Plain language by default.
Use everyday wording first. Technical language should appear only when helpful or requested.

3. Trust before cleverness.
Make data provenance, uncertainty, and user control visible.

4. Mobile first.
Design for iPhone first, not a desktop dashboard compressed onto a phone.

5. Calm visual tone.
Health is emotionally loaded. The UI should feel steady and legible.

## Platform and Navigation

- Platform: iPhone first
- Primary tabs: Today, Ask, Timeline, Experiments, Settings
- Primary data source: Apple Health
- AI: on-device assistant after local model download

## Screen Priorities

### Today
- Daily briefing
- Recovery or readiness
- Sleep summary
- Activity suggestion
- Health reminders
- Unusual changes
- Quick logging actions

### Ask
- Chat transcript
- Mode selector
- Source chips
- Inline chart support
- Data used inspector
- Citation or sources panel

### Timeline
- Date range controls
- Filters
- Chronological health events
- Compact metric overlays
- Manual events

### Experiments
- Hypothesis
- Intervention
- Primary metric
- Baseline vs intervention
- Confidence label
- Confounder notes

### Settings
- Apple Health status
- Local model status
- Profile and goals
- Detail preference
- Health memories
- Export and delete controls

## Visual Style

### Overall
- Native iOS controls where possible
- White or near-white backgrounds
- Graphite text
- Muted blue for primary actions
- Restrained use of green, amber, and red for health states
- Compact cards
- Subtle dividers
- Small corner radius
- Small charts and dense but readable data displays

### Suggested Palette
- Background: `#F6F7F4`
- Surface: `#FFFFFF`
- Primary text: `#1F2933`
- Secondary text: `#5B6673`
- Primary action: `#4F7892`
- Positive: `#5E8967`
- Caution: `#BE8A35`
- Alert: `#B55F52`
- Divider: `#D8DDE3`

### Typography
- Prefer iPhone-native typography similar to SF Pro
- Strong hierarchy with compact spacing
- Avoid oversized display text

### Components
- Tab bar
- Segmented control
- Compact cards
- List rows
- Sheets for inspectors
- Source chips
- Inline metric charts
- Compact status badges

## Content Behavior

- Always separate personal data observations from general medical context.
- Show uncertainty when confidence is limited.
- Prefer labels like "unusual for you" over alarming language.
- Make export, permissions, and privacy controls easy to find.

## Avoid

- Generic wellness startup styling
- Purple-heavy palettes
- Decorative gradients
- Marketing hero layouts
- Vague meditation or yoga illustrations
- Cards inside cards inside cards
- Overconfident diagnostic framing
- Dense desktop dashboard layouts on mobile
- Hidden data provenance

## Experience Goal

The user should feel oriented and capable within a few seconds. Xernia should feel like a calm daily health companion that helps the user understand what changed and what to do next.
